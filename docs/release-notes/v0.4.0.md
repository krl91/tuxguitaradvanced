## TuxGuitarAdvanced 0.4.0

The practice mode now recognises notes and chords **from what each attack adds to the sound**, so fingerstyle playing and chords over a ringing string are heard correctly.

### Highlights

* Polyphonic recognition by attack difference (non-negative least squares on harmonic templates, with a pitch-offset check and a guard against the pluck transient). On a real fingerstyle recording of a written score: 38 of 38 judged events recognised with no false acceptance, median delay 107 ms (before: 2 notes in 34).
* Chords with a note missing are refused (chord completeness rule, tuned on annotated recordings).
* Sharp allowance per fret for fretted notes (Recognition settings > Advanced).
* A benchmark on public annotated guitar recordings, run on demand, with a report of passed, failed and not-run tests.
* Score problems no longer open a dialog when a file is opened: *Edit > Display invalid measures* lists them on demand.
