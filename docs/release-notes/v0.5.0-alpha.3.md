## TuxGuitarAdvanced 0.5.0-alpha.3

Third alpha of the Arcade and tempo-following modes: a new look for the strings and the open string, from the owner's visual references.

**Package:** only **macOS (Apple Silicon)** is attached, built on the owner's Mac from the code of this tag (the GitHub Actions budget refuses the release jobs), with a Temurin 21 JRE embedded, signed ad hoc and **not notarised**: the first launch needs *Open Anyway* in *System Settings > Privacy & Security*. **There is no Linux and no Windows package for this alpha.**

### Changed in Arcade

* **New string colours, and the lowest string at the top.** From the lowest to the highest string: red, yellow, light blue, orange, green, violet. The neck now draws the lowest string at the top and the violet one at the bottom; the chord diagram keeps its usual orientation.
* **The string to play is lit.** The string of the active note, or every string of the active chord, is bright with a glow; the other strings are dim. The light goes out when the note is judged.
* **The open string is a bar.** A note at fret 0 is a thin horizontal bar in the colour of its string, as wide as the lanes, with a bright cap at its left end and the words "Open string" (*Corde à vide*, *Cuerda al aire*); it has no disk and no fret number. Inside a chord an open string stays an `O` of the diagram and is lit with the chord.
* **A chord is no longer dropped when its diagram cannot be placed**: it becomes a timing bar.

### Specification (not implemented yet)

The next increments, written in the specification after the owner's references: rounded rectangles instead of the disks, a thread and a footprint carrying the fret number, a highlighted fret ruler and an approach band (FR-070 to FR-072).

### Honest limits

Those of [0.5.0-alpha.1](https://github.com/krl91/tuxguitaradvanced/releases/tag/v0.5.0-alpha.1) still apply: alpha, not validated by other players, guitars, microphones or machines; about one audio-analysis deadline missed per minute in a 10-minute stress run (not rerun for this version); bass notes below G1 are shown but not judged; hearing your own guitar through the application is not offered. The manual and the README screenshots still show the previous colours.
