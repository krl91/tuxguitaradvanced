## 🎸 TuxGuitarAdvanced 0.7.0-beta.1 — a more forgiving *Follow the tempo*, and it tells you why a note was refused

TuxGuitarAdvanced adds **practice modes** on top of [TuxGuitar](https://www.tuxguitar.app/), the free multitrack tablature editor: it listens to your real guitar, checks the **pitch of the notes and the chords** you play against the tablature, and lets you practise note by note, in time (Follow, Arcade) or waiting for the right note.

### 🔖 About this release

A **pre-release** for feedback. Its main change, a more forgiving *Follow the tempo*, is still being tried by the author (the second play-through of the test sheet is under way); the settings below may still move.

### ✨ What is new since 0.6.0

* **Why a note was refused, in *Follow the tempo*.** Every note not accepted on time now says why: *no attack heard*, *wrong note*, *pitch not clear*, *played too early*, *played too late*, *chord incomplete*. The end-of-run summary counts each reason.
* **A time to play the note.** In *Follow the tempo*, a note counts from the moment it turns red until the **time to play the note** has gone by: **600 ms by default, adjustable from 100 to 1,200 ms** (Mode tab, and the Configuration window, section *Passages*). It may also come up to 50 ms early. When notes are close, the time stops just before the next one, so that one note never counts for two. Arcade keeps its own timing window.
* **A pitch permissiveness for *Follow the tempo*** (*Strict*, *Permissive* the default, *Very permissive*), separate from Arcade's. A wrong note, the neighbouring semitone included, is still refused.
* **The rhythm calibration is offered before you play.** When your input and output have no rhythm calibration, the start window of *Follow the tempo* and Arcade says so and offers **Calibrate now** or **Go on without** (asked once per launch). If the calibration fails, it says where the delay can be set by hand (Mode tab, *Delay (ms)*).
* **Record a run (optional).** Two boxes of the Mode tab keep a record of a run, and if you wish a copy of its sound, in a folder `tuxguitar-follow-takes` of your home folder, so that a problem can be measured on your own playing.
* **A greyed Start button says why** (for example: the input has heard nothing yet).
* Texts in English, French and Spanish; the user guide `docs/PRACTICE.md` describes the new settings.

### 🐞 Fixed

* The **rhythm calibration was always greyed out** (and its offer never shown): the application did not know the audio format of the input. Fixed.
* In *Follow the tempo*, **Restart at the end of a run did nothing**. Fixed (checked by a test; not yet tried by hand).

### ✅ What was checked, and by whom

* **Tests:** the full macOS build is green (about 1,280 practice tests and 378 audio-engine tests, 0 failures). The recognition figures on the reference recordings are unchanged, and Arcade's figures are unchanged.
* **Live, by the author:** *Follow the tempo* played on a Mac with a **Rocksmith USB guitar adapter**, rhythm calibrated, several recorded runs. They showed the right notes heard but played 0.4 to 0.7 s after they turned red, which is why the default time to play went from 300 to 600 ms. The verdict of the author on 600 ms is still to come.
* **Not checked by anyone yet:** the **Windows and Linux packages were never run** (built and their version read by the verifier only); other microphones, interfaces and computers.

### 🚧 What is **not** fixed

* Notes and chords whose **attack is not heard** (a soft note, a low input level) are still refused: no permissiveness changes the attack detection. Play firmly enough for the level meter to move.
* A chord with **one string missing** can still be accepted.
* The practice window's palette can cover the score; making it move aside is the next planned work.
* The macOS package is **not notarised**: the first launch needs *Open Anyway* (System Settings → Privacy & Security). The Windows package needs Java 17 or later.
* The practice modes exist only in the macOS, Linux and Windows **SWT** packages.
