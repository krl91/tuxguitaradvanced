## 🎸 TuxGuitarAdvanced 0.6.0 — calibration, Arcade in five levels, one version everywhere, and a macOS app that opens

TuxGuitarAdvanced adds **practice modes** on top of [TuxGuitar](https://www.tuxguitar.app/), the free multitrack tablature editor: it listens to your real guitar, checks the **pitch of the notes and the chords** you play against the tablature, and lets you practise note by note, in time (Follow, Arcade) or waiting for the right note.

### 🔖 About this release

This is the first release of the 0.6 line **without the pre-release label**. Its application is **the same as 0.6.0-beta.3**: only documentation changed since. Every package contains the whole application and all its libraries on the three systems, TarsosDSP included.

### ✨ What is new since 0.5.0

* **Calibration for your own microphone or interface.** The recognition can be tuned for your input from a recording of a short piece; the picture of the note or the chord to play is shown as a tablature image, one sound at a time. With no calibration profile, the recognition figures are the same as before.
* **Arcade in five levels.** Every start of Arcade asks the level: level 1 keeps about 30 % of the notes and no chord, level 2 30 % of the notes and 30 % of the chords, level 3 50 %, level 4 75 %, level 5 the whole piece. The first sound of each kind is always kept, the same sounds at every run; the sounds a level leaves out are played for you by the band, so the music stays complete.
* **A more forgiving Arcade, still adjustable.** A *Permissiveness* line (*Like Practice*, *Fun* the default, *Very permissive*) widens the timing window and relaxes some recognition thresholds, in Arcade only.
* **The same version and commit everywhere.** About shows `TuxGuitarAdvanced 0.6.0`, the short commit and the full commit, with a **Copy the version** button for bug reports; the window title, `--version`, the macOS `Info.plist`, the Windows exe, the Debian package, the file names and this page say the same. A local build says `dev`. How it works: `docs/VERSIONING.md`.
* **A macOS app that can be opened.** With the earlier releases, a downloaded app was called *damaged* by a strict macOS, with no way to open it. The application now lives in `Contents/Resources/tuxguitar` and the whole app is signed, so macOS gives the usual *« Apple could not verify… »* message and an **Open Anyway** button. **How to open it the first time:** unzip, move `TuxGuitarAdvanced.app` to *Applications*, double-click it and click **Done**; then *System Settings → Privacy & Security*, scroll to *Security*, click **Open Anyway** next to *« TuxGuitarAdvanced was blocked… »* and confirm with your password or Touch ID.
* Texts in English, French and Spanish; the user guide `docs/PRACTICE.md` describes the modes.

### ✅ What was checked, and by whom

* **Tests:** the full macOS build is green (1,172 practice tests, 373 audio-engine tests, 0 failures); the version scripts have their own self-tests.
* **macOS:** the author downloaded the 0.6.0-beta.3 package, which has this application, and it opens with the *Open Anyway* procedure above. The signature of the bundle is checked by the Release workflow before the package is attached.
* **The release itself is checked before it is published:** the workflow reads the version and the commit in every package and in the draft release, and the git tag after publication.
* **Not checked by anyone yet:** the **Windows and Linux packages were never run** (they were built, and the version in them was read by the verifier, including the Windows exe's version resource); the **About window's layout** and the Copy button on screen; the sound of the sounds Arcade removes (listened to by nobody yet).

### 🚧 What is **not** fixed

* A chord with **one string missing** can still be accepted: nothing here changes the recognition algorithms.
* The more forgiving Arcade recognises exactly the same notes as before on the recordings measured; the forgiveness you feel comes mostly from the wider timing window and from the levels.
* The macOS package is **not notarised** (no Apple Developer ID): the first launch needs *Open Anyway*. The Windows package needs Java 17 or later.
* The practice modes, the calibration and the Arcade levels exist only in the macOS, Linux and Windows **SWT** packages (not in the JavaFX, Qt or FreeBSD builds).
