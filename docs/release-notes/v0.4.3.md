## TuxGuitarAdvanced 0.4.3

A fix release for the Interactive Practice launch.

### Fixes

* **One click on the Practice button now goes straight to the practice.** The configuration window no longer appears: it only shows up if you have to act (no usable input, or the input is not ready after a short wait).
* **The tuner and Interactive Practice no longer step on each other.** Both listen to the same input and the tuner opened from the practice window displayed badly. The "Tune guitar" buttons are removed from the practice windows, and the tuner refuses to open while Interactive Practice is open, with a message telling you to close it first.

### Also in this release

* Documentation: README, [Interactive Practice guide](https://github.com/krl91/tuxguitaradvanced/blob/master/docs/PRACTICE.md) (English) and [guide en français](https://github.com/krl91/tuxguitaradvanced/blob/master/docs/PRACTICE-FR.md).
* Specification status brought up to date (`specs/STATUS.md`).

See [0.4.2](https://github.com/krl91/tuxguitaradvanced/releases/tag/v0.4.2) for the measured recognition quality, the known limits and the installation notes. Interactive Practice is in the macOS (Apple Silicon) package only.
