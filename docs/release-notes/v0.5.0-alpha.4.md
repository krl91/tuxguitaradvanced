## TuxGuitarAdvanced 0.5.0-alpha.4

Fourth alpha of the Arcade and tempo-following modes: the Arcade picture rebuilt from the owner's reference screenshots, and a one-click start.

**Package:** only **macOS (Apple Silicon)** is attached, built on the owner's Mac from the code of this tag (no GitHub Actions workflow was run), with a Temurin 21 JRE embedded, signed ad hoc and **not notarised**: the first launch needs *Open Anyway* in *System Settings > Privacy & Security*. **There is no Linux and no Windows package for this alpha.**

### Arcade: the picture

* **Rounded rectangles instead of disks.** A note is a rounded rectangle in the colour of its string; it is as wide as the cell of its fret at its depth, so a higher fret is a narrower rectangle, and it lands exactly on its target rectangle on the neck.
* **The note arrives at the foot of the neck.** It goes in **one straight line** from the horizon to its cell, through the see-through neck, and stands on a small footprint on that line, joined by a thin thread: the red string, at the top of the neck, has the longest thread, the violet one the shortest. At the onset the rectangle is on its target.
* **See-through neck**, with the lanes seen under it, a faint approach band, and the fret ruler highlighting the fret of the active note.
* **A chord is a translucent panel** from its first to its last fret, with a rounded rectangle for each note, its name above the left corner, and the fret numbers on the active chord.
* **A floating measure**: the picture holds the notes of the next measure of the track (one second at least), not a fixed five seconds, so it is less crowded.
* **Calmer picture**: only the active note glows, finer lines.
* **The plane is tilted** (scale at the horizon 35 %, horizon at 18 % of the height) and both are **settings** in the preparation window (Mode tab), as is the size of the markers (0 to 150 %).

### Arcade: use

* **A coloured Arcade button in the transport bar** (after the Practice button) starts Arcade at once on the track under the cursor, with the current input, in a window that fills the screen width. It starts even when the guitar is not played yet.
* **A Restart button** in the game window starts the piece again from its beginning (or from the passage that was started) without leaving the game.
* **A default input**: a *Remember as default* button stores the chosen input in the configuration; it is selected when it is there, and again when it comes back after an absence. A *Refresh* button reads the list of inputs again.
* The tuner needle is exactly vertical inside the in-tune range.

### Fixed on the way

A run started right after the input was opened failed on a lag spread not measured yet; the preparation window could come over a game; the end of a run that was given back could stop the next one.

### Honest limits

Those of [0.5.0-alpha.1](https://github.com/krl91/tuxguitaradvanced/releases/tag/v0.5.0-alpha.1) still apply: alpha, not validated by other players, guitars, microphones or machines; about one audio-analysis deadline missed per minute in a 10-minute stress run (**not rerun for this version**); bass notes below G1 are shown but not judged; hearing your own guitar through the application is not offered. For this version the unit tests (777) and the native tests (23) pass, the real-score corpus run was **not** repeated, and the buttons, the default input with a second device and the settings spinners were only checked by hand on one machine. The game window fills the screen width but is not the native macOS full screen. The settings of the tilt and of the marker size are kept for the session, not in the configuration. **The manual and the README screenshots still show the previous look.**
