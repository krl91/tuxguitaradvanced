## TuxGuitarAdvanced 0.4.1

A fix and diagnostics release on top of 0.4.0.

### Improvements

* The red cross "wrong note" is shown only for a note that was just struck, not for the previous note still ringing: playing notes one by one, with the previous one still sounding, no longer shows false errors.
* **Practice diagnostic trace**: an optional text trace (derived numbers only, no audio) of what Practice heard and decided. See the [user guide](https://github.com/krl91/tuxguitaradvanced/blob/master/docs/PRACTICE.md#diagnostic-trace-to-understand-a-failure).
* New tests on annotated recordings: next note while the previous one rings, and simulated hammer-on / pull-off.

### Notes

See [0.4.2](https://github.com/krl91/tuxguitaradvanced/releases/tag/v0.4.2) for the full list of changes since 0.3.0, the measured quality and the known limits. The Interactive Practice modules are in the macOS (Apple Silicon) package only.
