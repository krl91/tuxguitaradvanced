## TuxGuitarAdvanced 0.5.0-alpha.2

Second alpha of the Arcade and tempo-following modes: two fixes, and a complete user manual with a worked example.

**Package:** only **macOS (Apple Silicon)** is attached. It was built on the owner's Mac from the code of this tag (the GitHub Actions budget refuses the release jobs), with a Temurin 21 JRE embedded, signed ad hoc and **not notarised**: the first launch needs *Open Anyway* in *System Settings > Privacy & Security*. **There is no Linux and no Windows package for this alpha.**

### Fixes

* **The tuner needle is vertical when the note is in tune.** It tilted for a note a few cents off even though the tuner said "in tune", because the needle used a linear scale of ±50 cents and the in-tune range is ±5 cents. It is now exactly vertical for every deviation inside the in-tune range, and moves continuously from the edge of that range to the end of the dial. A unit test reproduces the old behaviour (it failed first).
* **The practice window comes back after an Arcade run.** After a run whose result was shown, *Tools > Interactive Practice* did not bring the window back; it is now shown again, recomposed from the settings and repainted. A native SWT test reproduces the hidden window (it failed first).

### Documentation

* **User manual** in [English](https://github.com/krl91/tuxguitaradvanced/blob/master/docs/MANUAL.md) and [French](https://github.com/krl91/tuxguitaradvanced/blob/master/docs/MANUAL-FR.md): editing and creating a score, the whole Practice, and a **complete worked example** (a three-track song of guitar, bass and drums, normal playback, then the three practice modes), with screenshots of the application.

### Honest limits

Those of [0.5.0-alpha.1](https://github.com/krl91/tuxguitaradvanced/releases/tag/v0.5.0-alpha.1) still apply: alpha, not validated by other players, guitars, microphones or machines; about one audio-analysis deadline missed per minute in a 10-minute stress run; bass notes below G1 are shown but not judged; hearing your own guitar through the application is not offered. The tuner fix changes the display of the needle, not the pitch detection.
