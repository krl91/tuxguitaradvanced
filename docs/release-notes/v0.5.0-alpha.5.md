## TuxGuitarAdvanced 0.5.0-alpha.5

Fifth alpha of the Arcade and tempo-following modes: the techniques written in the score are now drawn, on the note while it is coming and again on the neck when it is the note to play.

**Package:** only **macOS (Apple Silicon)** is attached, built on the owner's Mac from the code of this tag (no GitHub Actions workflow was run), with a Temurin 21 JRE embedded, signed ad hoc and **not notarised**: the first launch needs *Open Anyway* in *System Settings > Privacy & Security*. **There is no Linux and no Windows package for this alpha.**

### New in Arcade

* **Bends are drawn.** While the note is coming, a small dashed arrow rises from the right end of its rectangle with the amount of the bend. When it is the note to play, a **ghost rectangle in dashed outline** appears on the same string at the fret the bend reaches (one fret per semitone), joined to the target by a dashed arrow with the amount above it. The amount is in steps: ¼, ½, ¾, *full* (a whole tone, *entier* / *entero*), 1½, 2... *pre* before it is a pre-bend, ↓ after it a release.
* **The other techniques are drawn too**, in the same yellow, only on single notes: **hammer-on and pull-off** (a small arc and the letter H or P in flight; on the neck the ghost of the next note of the string and a dashed arc to it, *H/P* when the direction is not known), **slide** (a dashed rail and S), **vibrato** (a wave), **palm mute and tapping** (pills P.M. and T), **tremolo picking** (three short strokes). A **harmonic** is a bar that says *Harmonic ◇* instead of *Automatic*. Chords, slapping, popping, accents, let ring and staccato show nothing.
* **What is checked has not changed:** the timing and the pitch (the written path of a bend, the destination note of a hammer-on, a pull-off or a slide). **No technique is reported as detected or not detected**: the detectors are not validated (bend 82 %, vibrato 59 %, slide 48 % of the annotated notes, 85 % needed; none for hammer-on and pull-off; none at all for palm mute, tapping and tremolo picking). The manual says so in a table.
* The label of the size setting now says *rectangles*, not *discs*.

### Documentation

The manuals, the practice guides and the README (English, French, Spanish) describe the Arcade picture of 0.5.0-alpha.4 and of this version, with new screenshots (French and English).

### Honest limits

Those of [0.5.0-alpha.1](https://github.com/krl91/tuxguitaradvanced/releases/tag/v0.5.0-alpha.1) still apply: alpha, not validated by other players, guitars, microphones or machines; about one audio-analysis deadline missed per minute in a 10-minute stress run (**not rerun for this version**); bass notes below G1 are shown but not judged; hearing your own guitar through the application is not offered. For this version the unit tests (806) and the native tests (23) pass; the real-score corpus run was **not** repeated. The marks of the techniques were checked by the tests on a recording painter and on pictures rendered by a test painter: **the dashes were not checked on the native canvas by the author**, and the marks are small while a note is coming. The two pictures of the techniques in the manual are rendered by a test program from the scene of the game, not screenshots of the application.
