## TuxGuitarAdvanced 0.4.2

TuxGuitarAdvanced is an advanced version of TuxGuitar: the same editor and player, plus a practice mode that **listens to your guitar**, a steadier tuner and tools to check your scores. This release gathers everything since 0.3.0 and makes the practice mode work on the music people actually play: fingerstyle, arpeggios and chords, with the previous note still ringing.

### Highlights

* **Practice recognises notes and chords over ringing strings.** Notes and chords are now recognised from *what each attack adds to the sound*, so a melody over a ringing bass, or the next note while the previous one still sounds, is heard correctly. Before, the single-pitch detector followed the bass and most notes of a fingerstyle piece were never recognised (2 notes in 34 on our reference recording).
* **A steadier tuner.** The needle shows the median of the confident readings of the last quarter second: it no longer shakes with every reading and no longer freezes when a string fades.
* **Score analysis on demand.** Opening a Guitar Pro or MIDI file no longer interrupts you with a dialog about invalid measures. *Edit > Display invalid measures* (or the toolbar icon) lists every problem of the song, with filters and a one-click fix.
* **Measured on real recordings.** The recognition was tuned and checked on more than 1,200 annotated recordings of real guitars (single notes, intervals, chords; clean and with 11 audio effects), 6,178 automatic tests, plus a real fingerstyle recording of a written score.

### New

* Chords with a note missing are refused (96 to 98 % of the time on the benchmark; it was 33 % before): every separable note of a chord must show growth of its own. Octaves and twelfths, which audio cannot tell from a partial of the lower note, are not compared.
* *Sharp allowance per fret* (Recognition settings > Advanced, 0.7 cents per fret by default): pressing a string on a fret stretches it, so fretted notes sound a little sharp, more so higher up the neck. This accepts it on the sharp side only; 0 switches it off.
* An optional **diagnostic trace** for practice (numbers only, no audio) to understand why a note was or was not recognised: see the [user guide](https://github.com/krl91/tuxguitaradvanced/blob/master/docs/PRACTICE.md#diagnostic-trace-to-understand-a-failure).
* A benchmark you can run on your own annotated recordings, with a report of tests passed, failed and not run (and why).
* New documentation: README, [Interactive Practice guide](https://github.com/krl91/tuxguitaradvanced/blob/master/docs/PRACTICE.md) and its [French version](https://github.com/krl91/tuxguitaradvanced/blob/master/docs/PRACTICE-FR.md).

### Improvements

* The red cross "wrong note" is shown only for a note that was just struck, not for the previous note still ringing.
* **Stop** ends the practice immediately instead of waiting behind queued audio analysis.
* Release packages are attached to the release directly by the build, without intermediate storage.

### Measured quality (details in the user guide)

| | Result |
|---|---|
| Single notes recognised | 99.8 % (with effects) to 100 % (clean) |
| A note a semitone or a tone away accepted | none in more than 2,700 tests |
| Intervals and triads with effects recognised | 87 % |
| Chords of clean guitars recognised | 95 % |
| Chords with a note missing refused | 96 to 98 % |
| Next note recognised while the previous one rings | 97 to 100 % |
| Delay before a note is recognised | about 0.1 s (median) on a real recording |
| Automatic tests in the default build | 479 |

### Known limits

* Chords whose lowest note is G2 are sometimes accepted a whole tone higher; four-note seventh chords and some open chords (A major, E major) are recognised less often; on our reference recording three chords with a quiet upper note are not recognised.
* Notes less than about 0.15 s apart (fast triplets) cannot be told apart by audio: Practice waits for you.
* Hammer-ons and pull-offs are accepted from their pitch. This was checked on simulated legato only; use the diagnostic trace if one does not pass.
* The Interactive Practice modules are part of the **macOS (Apple Silicon)** package only for now. The Linux and Windows packages are the standard editor.

### Installation

* **macOS (Apple Silicon)**: unzip `TuxGuitarAdvanced-v0.4.2-macos-arm64.zip` and open `TuxGuitarAdvanced.app`. The package is signed with a self-made certificate and not notarised: the first time, allow it in *System Settings > Privacy & Security > Open Anyway*. The microphone permission is asked on first use of the practice mode or the tuner.
* **Linux (x86_64)**: extract `TuxGuitarAdvanced-v0.4.2-linux-x86_64.tar.gz` and run `TuxGuitarAdvanced/tuxguitar.sh` (Java 17 or later).
* **Windows (x86_64)**: unzip `TuxGuitarAdvanced-v0.4.2-windows-x86_64.zip` and run it (Java 17 or later is required; it is not embedded).
