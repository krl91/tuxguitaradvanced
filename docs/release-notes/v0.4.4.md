## TuxGuitarAdvanced 0.4.4

Interactive Practice, the steadier tuner and the audio engine are now in the **macOS, Linux and Windows** packages, and practice starts to look at the **playing techniques** written in the score.

### New

* **Practice on Linux and Windows.** The three packages carry the same practice mode, tuner and audio engine. The Linux and Windows builds are compiled and tested by the project's CI; the macOS build is the one used day to day, so please report anything that behaves differently on your system (microphone access and audio inputs depend on the system's Java Sound support).
* **Technique line in the practice window.** For each written technique (hammer-on, pull-off, slide, bend, vibrato) the window shows what was heard: *heard*, *not heard*, *uncertain* or *cannot be checked yet*. It sits beside the pitch result and never blocks the exercise.
* **Technique detectors for vibrato, bend, slide and legato**, measured on 252 annotated recordings (IDMT-SMT-Guitar dataset 2).

### Honest limits

No technique is *verified* yet: the measured detection is 59 % for vibrato, 82 % for bend and 48 % for slide (target 85 %), and there is no annotated recording of hammer-ons or pull-offs to measure the legato detector. Until a technique meets its target, practice shows it as "cannot be checked yet" instead of guessing. The measured numbers are in `specs/002-practice-industrialization/benchmark/technique-benchmark-2026-10-06.txt`.

### Also in this release

* Documentation: the tuner is described in full (modes, tunings, needle, input, why it refuses to open during practice) in the [English](https://github.com/krl91/tuxguitaradvanced/blob/master/docs/PRACTICE.md) and [French](https://github.com/krl91/tuxguitaradvanced/blob/master/docs/PRACTICE-FR.md) guides.
* Build: the fork modules pin Maven surefire 3.2.5, so the Linux build runs their JUnit 5 tests.

See [0.4.2](https://github.com/krl91/tuxguitaradvanced/releases/tag/v0.4.2) for the measured recognition quality of notes and chords and the installation notes (the macOS package is signed with a self-made certificate: the first launch needs "Open Anyway" in System Settings; the Windows package needs Java 17+ installed).
