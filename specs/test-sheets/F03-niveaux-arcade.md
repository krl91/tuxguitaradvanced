# F03 — Arcade : les cinq niveaux et la permissivité

- **Spec Kit** : `specs/014-arcade-fun-levels`
- **Tâche fermée** : T040 [HUMAN]
- **Exigences** : FR-006 (niveau proposé), FR-010 (résultat), FR-015 et SC-007 (les sons retirés entendus dans l'accompagnement), SC-006 (**est-ce amusant ?**)
- **Matériel** : guitare (Rocksmith ou micro intégré).
- **Partition** : `tests/demo-arcade-morceau.tg`
- **Durée** : 20 minutes.

**Important pour l'étape 1** : « la première fois » veut dire qu'aucun niveau n'a encore été choisi. Si tu as déjà joué en Arcade avec la version 0.6.0, le niveau proposé sera le dernier choisi ; note-le simplement.

## Étapes

| # | Fais | Attendu | OK / KO | Ce que j'ai vu |
|---|---|---|---|---|
| 1 | Ouvre la partition et lance Arcade (bouton pyramide de la barre de transport, ou Mode › Arcade dans la fenêtre de pratique). Regarde la ligne **Niveau** de la fenêtre de départ. | La première fois : **Niveau 1 : 30 % des notes, aucun accord** est proposé. | | |
| 2 | Choisis **Niveau 3 : 50 % des notes et des accords** et démarre. | Seule environ la moitié des notes et des accords arrivent à jouer. La **première** note du morceau est toujours gardée. | | |
| 3 | Écoute pendant que tu joues. | Les sons **retirés** sont **joués par l'accompagnement** : la musique paraît **complète et en rythme** (pas de trous, pas de décalage audible). | | |
| 4 | Joue les sons gardés jusqu'à la fin. | Le résultat **nomme le niveau** (« Niveau 3 (50 % des notes, 50 % des accords) ») **et la permissivité**. | | |
| 5 | Quitte complètement l'application, relance-la, relance Arcade. | **Niveau 3** est proposé. | | |
| 6 | Change la **Permissivité** (jusqu'à **Très permissif**), rejoue le même passage en faisant exprès des « à-peu-près » (un peu en avance, un peu en retard). | Tu sens une différence : les à-peu-près passent plus facilement. (Mesuré : la permissivité ne change rien sur l'enregistrement de référence. Ton ressenti compte ici.) | | |
| 7 | Essaie le **Niveau 5** (tout) puis le **Niveau 1**. | Au niveau 5, l'accompagnement ne joue **aucun** son retiré (il n'y en a pas). Au niveau 1, il n'y a **aucun accord** à jouer. | | |

## Ta réponse (SC-006)

- **Est-ce amusant ?** Oui / Non / Pourquoi.
- Les sons retirés sonnent-ils **en rythme** ? Oui / Non (où, si non).
