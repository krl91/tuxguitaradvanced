# Tasks: Per-device calibration of the recognition

**Input**: `specs/013-device-recognition-calibration/` (spec.md with its Clarifications of 2026-10-15 in three passes, plan.md P0 to P6, research.md R1-R11, data-model.md, contracts/profile-library.md, calibration-flow.md, scoring-search.md, quickstart.md, checklists/calibration.md)

**Prerequisites**: spec.md (US1 to US5, FR-001 to FR-019, SC-001 to SC-009). **No recognition algorithm changes; with no profile every figure is as before; no audio is ever written to disk; the bass is out of scope (FR-018).**

**Tests**: written **before** the code they test and seen failing (a compile error counts; say so).

**Note on the checklist**: the unchecked items of `checklists/calibration.md` belong to the owner as reviewer; items he judges failing (for example CHK003, CHK007, CHK028, CHK030, CHK035) may add or change tasks, and the spec is amended first.

**Conventions**: `AE` = `desktop/TuxGuitar-audio-engine/src/main/java/app/tuxguitar/audio/engine`, `AET` = `desktop/TuxGuitar-audio-engine/src/test/java/app/tuxguitar/audio/engine`, `SRC` = `desktop/TuxGuitar-practice/src/app/tuxguitar/app/tools/custom/practice`, `TST` = `desktop/TuxGuitar-practice/test/app/tuxguitar/app/tools/custom/practice`, `SPEC` = `specs/013-device-recognition-calibration`, `BUILD` = `desktop/build-scripts/tuxguitar-macosx-swt-cocoa` (with `JAVA_HOME` on JDK 21). Each task ends with the FR and SC it protects.

**Existing tests stay unchanged** (owner's rule, 2026-10-15): no existing test file is modified, renamed or deleted — new tests only. Checked against the source: `PracticeHostSourceTest` forbids `AudioEngine.getInstance(` in `PracticeWindow.java` and counts it, `new Thread(` and the other calls exactly once in `AppPracticeHost.java`, so **neither file is edited** (the worker thread of the search goes in `CalibrationController`, through `TGThreadManager`); `PreRunParityTest` forbids `HopListener`, `StrumClipMeter`, `PreRunCheck` in `arcade/core`, `PracticeSession.java`, and the engine's `pitch` and `recognition` directories, so **all new engine code lives in the new `calibration` package** and none of those four is edited; `DatasetJudge` and its callers are **copied from, not moved**; the public API of `RecognitionSettingsStore`, `FollowSettings` and `AudioRecognitionOption` only grows, and with no profile behaves exactly as before; new texts are added to the three language files together; `RecognitionParameters.ALL` is not changed (so `RecognitionControlsTest` and the help rows stay as they are); the contract toolkit (`SwtContractToolkit`) is only extended, never changed in what it already answers. **Each phase ends with `git diff --name-status <phase start>` showing no `M`, `D` or `R` on a file under a `test`, `src/test` or `test-data` directory** (additions `A` only), and the whole default suite equal to the baseline plus the new tests.

**Rules for every phase**: commit locally at the end of the phase with no co-author trailer and a message saying which tests failed first; stage explicit paths (never `git add specs`); never push (the owner asks); keep the build green; **run the whole default practice suite after a clean compile** (`mvn clean test -pl ../../TuxGuitar-practice -am` from BUILD) and compare it to `specs/012-adjustable-timing-window/benchmark/after.txt` (937 tests); report exactly what ran and what was skipped; never commit the owner's recordings.
