# The frame record (spec 023, data-model "Frame record"): one record per analysis window, in a float[] (Java) or [f32] (Rust).
# A long or a double takes two slots: the high then the low 32 bits, as raw float bits. An int or a count is a float value.
# The header's slots, read by frame.rs's tests (Rust) and FrameRecordsTest (Java); each side's constants must equal these.
